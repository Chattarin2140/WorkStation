 SCANNER — ยามเฝ้าตลาด (สแกนทุก 20 วินาที)
  คำนวณ indicator เอง (MA, RSI, ATR, ADX, MACD, swing, เทรนด์ H1) หา "จังหวะน่าเข้า"
  → ไม่กิน AI เลย เจอจังหวะค่อยปลุกทีม (ประหยัด)

  ดึงข่าวสด (ฟรี ไม่กิน AI)
  - Yahoo Finance → ข่าว + DXY + พันธบัตร US
  - Binance → funding + long/short ratio
  - Fear & Greed → อารมณ์ตลาด

HAWK ×3 — ทีมนักวิเคราะห์ (AI 3 มุมมอง)
  นักวิเคราะห์ 3 คน คิดแยกกัน: สายเทรนด์ / สายโครงสร้าง / สายสวนกระแส
  → โหวต ต้อง 2 ใน 3 เห็นตรงกันถึงจะเข้า (ไม่เอกฉันท์ = พับ)

SAGE — หัวหน้าฝ่ายความเสี่ยง (AI)
  ตรวจซ้ำอิสระ มีสิทธิ์ VETO ยับยั้ง! ปรับ SL/TP ให้คุ้มก่อนปล่อยผ่าน
  → "เด็กวิเคราะห์อยากเข้า แต่พี่ความเสี่ยงเบรกได้"

 กฎเหล็ก (โค้ด ไม่ใช่ AI)
  ด่านสุดท้าย ไม่มีอารมณ์: เช็ค R:R, spread, ขนาดไม้, เพดานขาดทุนต่อวัน
  → AI เสนอได้ แต่กฎเหล็กหนีบทุกค่า กันบ้าระห่ำ

เข้าออเดอร์ (MT5)
  เช็คราคาล่าสุดอีกรอบ → ล็อก reward:risk → ตั้ง TP แบบขั้นบันได (ปิดครึ่งกำไรแรก เลื่อน SL มาทุน ปล่อยที่เหลือวิ่ง)

📊 บันทึก + เรียนรู้
  ทุกไม้ลงฐานข้อมูล → report รายวัน/สัปดาห์/เดือน + บอทจำบทเรียนจากไม้ที่แพ้ เอาไปเตือนตัวเองรอบหน้า
